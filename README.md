# frontendmentor
First practice project on frontendmentor

The challenge I took on first was to recreate an article preview that has a small amount of JS interactivity. The design is intended to reflect the example and produce a popup menu when the share icon is clicked. The design is also supposed to be responsive to mobile devices (width of 375px according to design document).

The live solution can be found here: https://ampedro15-rgb.github.io/frontendmentor/

I didn't use anything super crazy while working on this. It took me about 9 hours to complete. The thing newest to me was using flexbox, since I originally started learning web design in order to create a blog in the style of 2000s neocities blogs, I wasn't planning on using more modern innovations. In fact, I wasn't planning on learning responsive design whatsoever, as my original vision for the blog project was to be faithful to the time and not load the website well on mobile devices. But anyways, that's not relevant to this project.

While working on this I was surprised at how much I was able to complete on my own without outside resources as I only started learning HTML/CSS/JS a week ago. CSS was the area where I ended up needing the most help. I learned how to create that text bubble shaped popup using creative border workarounds as well as how to play with overlay and spacing. I also learned the importance of inheritence and priority, and I'm not confident I coded the popup to hide/unhide in the best way since I ended up having to use the !important attribute.
